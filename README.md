# CursorDataOpsAnalytics

Personal workspace for DataOps / Analytics Platform daily activity tracking via Cursor Cloud Agent.

## Files

| File | Purpose |
|------|---------|
| [`daily-log.md`](daily-log.md) | Daily activity and todo list (source of truth) |
| [`AGENTS.md`](AGENTS.md) | Instructions for Cursor / Cloud Agent sessions |

## Usage

1. Open this repo in Cursor (local or Cloud Agent).
2. Start an agent session — it reads `AGENTS.md` and `daily-log.md`.
3. Add, update, or cross out todos in chat; the agent updates `daily-log.md`.
4. Commit and push to sync across devices.

## Cloud Agent

Start a Cloud Agent at [cursor.com/agents](https://cursor.com/agents) against `fcrivero/CursorDataOpsAnalytics` (branch: `main`).
