## Rules

- Sequential numbering — never reuse or skip numbers.
- Done items stay in the list but are crossed out (`~~text~~`).
- In-progress items carry the legend `**In progress**` right after the number.
- New items get the next number (update the "Next item number" header).
- **Cross-out rule:** every time an item is crossed out, drop any `**In progress**` legend, then **resort + renumber** the full list immediately.
- **In-progress rule:** when an item is marked in progress, add `**In progress**` after the number, then **resort + renumber**.
- **Resort rule:** group into three tiers and renumber 1…N with no gaps — **Done** (crossed out) first, then **In progress**, then not-started **Open** items last. Keep existing relative order within each tier.
- **Consolidate rule:** merge duplicate open items into one line (keep links). Remove the duplicate — never add "Consolidated into #X" placeholder lines.
- **Monthly rollover:** at the start of each new month, freeze the previous month's completed (crossed-out) items into `<month>-log.md`, then start a fresh `daily-log.md` carrying forward only the **in-progress** and **open** items, renumbered from 1 (in-progress first, then open).
- Update this file whenever items are added, changed, completed, or resorted.
- After every change, auto-sync (commit + push) via `scripts/sync-log.sh`.
- Archives: [`july-log.md`](july-log.md) (July 2026), [`august-log.md`](august-log.md) (closed August & September 2026 items), and [`october-log.md`](october-log.md) (closed October 2026 items).
